一个专门猜 HOYO-MiX（米哈游）音乐的网页游戏。歌曲存放在 Backblaze B2 云存储（私有桶）中，部署在 Vercel 上，随时随地打开网页就能玩。

拥有从崩坏学园2到绝区零的HOYO-MiX全曲库，快来挑战，来证明你是否是HOYO-MiX的忠实粉丝吧！！🎵

## 功能特性

- 🎵 **歌曲来源**：从 Backblaze B2 私有桶读取歌曲，支持“游戏名文件夹 / 子文件夹 / 歌曲.mp3”的层级结构，自动按游戏分类
- 🎮 **多种玩法**：
  - **自选模式**：先选曲库（点进游戏可选“全部曲目”或具体专辑），再设置题目数（不能超过曲库歌曲数），答完自动结算
  - **无尽模式**：选曲库（可选专辑）后直接开始，永不结束，手动“结束本轮”才结算
  - **混合模式**：从整个歌库随机出题
  - **双人模式**：P1/P2 同屏抢答，先答对者得分，双方都错本题作废，跟随所选模式结算

- 🎯 **干扰项规则**：所选游戏曲目 ≥ 20 首时，错误答案只从该游戏内挑选；不足 20 首时，允许从整个歌库抽取干扰项
- 👥 **双人对战**：左侧 P1 圆形按钮（键盘 Q/W/E/R），右侧 P2 圆形按钮（键盘 U/I/O/P），中间统一显示歌名；触摸设备显示 A/B/C/D
- 🎧 **自定义播放器**：完全手写的播放/暂停、进度条拖动、时间显示、音量控制，深空磨砂玻璃风格
- 🌓 **明暗主题**：一键切换深色（星空）/ 浅色（暖黄）主题，自动记忆选择
- 🔔 **背景音乐**：支持开关，进入游戏时自动暂停、回到主菜单恢复
- ⌨️ **键盘答题**：PC 端单人按 A/B/C/D，双人 P1 按 Q/W/E/R、P2 按 U/I/O/P
- 📊 **完整结算**：答对数、答错数、正确率、总出题数、跳过数
- 🎉 **胜利特效**：所有模式结算时都有金色光晕 + 彩纸庆祝

## 技术栈

- 后端：Node.js + Express
- 前端：原生 HTML + CSS + JavaScript（无任何前端框架）
- 存储：Backblaze B2 云存储（私有桶）
- 部署：Vercel（GitHub 自动部署）

## 本地运行

环境要求：Node.js 18 或更高版本。

```bash
# 1. 安装依赖（第一次需要）
npm install

# 2. 准备 B2 配置：复制下方内容保存为 config.js（密钥换成你自己的）
```

```js
module.exports = {
  b2Endpoint: 'https://api.backblazeb2.com',
  b2KeyId: '你的密钥ID',
  b2ApplicationKey: '你的应用密钥',
  b2BucketName: '你的桶名'
};
```

```bash
# 3. 启动服务器
npm start

# 4. 浏览器打开
http://localhost:3000
```

注意事项：

- 桶内 `BGMusic/` 文件夹下的音频不会被当作题目歌曲；
- 支持背景音乐格式：mp3 / wav / ogg / m4a / flac。

## 游戏说明

1. 主菜单选择“自选模式”或“无尽模式”；
2. 在“选择曲库”页面选择“混合模式”或某个游戏（点进游戏可再选“全部曲目”或具体专辑）；
3. 选择“单人模式”或“双人模式”（自选模式还需填写题目数）；
4. 随机播放一首歌，从 4 个选项中选出歌名；
5. 答对变绿、答错变红并高亮正确答案，1.5 秒后进入下一题；
6. 结算页面显示统计，并展示胜利特效。

### 双人模式

- P1 使用左侧圆形按钮（键盘 Q/W/E/R），P2 使用右侧圆形按钮（键盘 U/I/O/P），中间统一显示歌名；
- 先答对者得分，另一人不得分；双方都答错本题作废；
- 结算显示 P1/P2 得分对比，分高者胜（平局显示“平局”）。

## 常见问题

**歌单是空的？**

- 检查 B2 桶里是否真的上传了 mp3 文件；
- 新上传的文件需要等待 60 秒缓存过期后刷新页面；
- 检查环境变量或 `config.js` 中的密钥和桶名是否正确。

**标签页图标不显示？**

- 强制刷新页面（Ctrl + F5）或用无痕窗口打开；
- 确认 `public/icon.png` 存在（部署后访问 `/icon.png` 应返回图片）。

**播放歌曲时没声音？**

- 点击页面任意位置解锁浏览器自动播放限制；
- 确认歌曲文件本身可以正常播放。
